About This Project

Project Overview

VisionLens AI is a Flask-based web application that demonstrates the integration of artificial intelligence with web technologies. The project was developed as part of the RECESS Final Project 2026 for BSE2301 Software Engineering Mini Project 2.

The application provides a friendly interface for text intelligence and image recognition. Users can submit text or a picture and receive a ranked prediction with a confidence score in real time.

Technology Stack

  • Backend: Flask (Python)
  • AI/ML: Custom NLP models
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
  • Database: SQLite
  • Deployment: Gunicorn, Docker-ready

Key Features

  • Real-time sentiment analysis
  • Text classification capabilities
  • Spam detection
  • RESTful API endpoints
  • Responsive web design
  • Easy-to-use interface
