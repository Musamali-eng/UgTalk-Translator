Project Overview

UgTalk & VisionLens AI is an AI-Powered Web Service built with Flask that combines language translation and intelligent text/image analysis.

The system uses Machine Learning for:

  • Translation: TF-IDF vectorization and Nearest Neighbors for Ugandan languages
  • Text Analysis: Sentiment analysis, text classification, and spam detection
  • Image Analysis: Pretrained vision models for image classification
Dataset: Language_translation_models_dataset.csv — 2,000+ records from 7 Ugandan languages
Status: Production Ready — Deployed with Docker
